5. Viewport, Media Queries, Image and Video

Viewport

This webpage contains the viewport meta tag: 

<meta
    name="viewport"
    content="width=device-width, initial-scale=1.0"
>

It allows the webpage to use the device width and display correctly on different screen sizes.

Media Queries

Resize the browser window to see the grid, navigation and hero image change at different screen widths. 

@media (max-width: 800px) {
    .grid-three {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (max-width: 600px) {
    .grid-three {
        grid-template-columns: 1fr;
    }
}
