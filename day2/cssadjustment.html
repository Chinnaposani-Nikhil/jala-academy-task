Display Property

display: none
display: inline Another inline element
display: block
display: contents
display: list-item

display: none removes the element from the layout.

display: inline keeps the element in the same line when space is available.

display: block makes the element behave like a block-level element.

display: contents causes the element's box to disappear while its children participate in the layout.

display: list-item makes the element behave like a list item.
