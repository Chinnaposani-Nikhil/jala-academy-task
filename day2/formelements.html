4. Target Attribute

The target attribute specifies where the linked document should be opened.

Open Google using target="_blank"

Open sample page using target="_self"

target="_blank"

Opens the linked page in a new tab or browsing context.

target="_self"

Opens the linked page in the current tab or browsing context. This is the default target behavior.

Input Attribute Summary

Attribute Purpose
disabled Prevents the user from interacting with the input.
max Sets the maximum allowed value.
maxlength Sets the maximum number of characters.
min Sets the minimum allowed value.
readonly Allows viewing but prevents editing.
required Requires the user to enter a value before submission.
size Specifies the visible width of certain text inputs.
value Specifies the initial value of an input.
