ng-options vs ng-repeat

ng-options ng-repeat
Designed specifically for generating select options. General-purpose directive for repeating HTML elements.
Works directly with ng-model. Creates individual <option> elements.
Generally preferred for select lists. Useful when you need more control over the option markup.
