3. CSS Position Properties

CSS position controls how an element is placed on a webpage.

Sticky Position
Static: This is the default position.
Relative: This element is moved 30px from its normal position.
Absolute: Positioned relative to the nearest positioned parent.

The parent container has position: relative. Therefore, the absolute element is positioned according to this container.

Scroll the page to observe the sticky element.

Positioning allows us to control the location of elements without changing the HTML structure.

4. Handling Overflow

When content is larger than its container, overflow can be handled using the overflow property.

Scrollable Content

This content is intentionally larger than its parent container.

Because overflow is set to scroll, scrollbars are available for viewing the hidden content.

Horizontal and vertical scrolling can be used depending on the size of the content.

CSS overflow values include visible, hidden, scroll and auto.

This is an example of handling overflow using the scroll value.

CSS Effects Summary

  • box-shadow - creates shadows around elements.
  • animation - creates movement and visual effects.
  • pagination - divides content into multiple pages.
  • position - controls element placement.
  • overflow - handles content larger than its container.
  • opacity - controls element transparency.
