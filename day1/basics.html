About HTML

HTML stands for HyperText Markup Language. It is used to create the structure of webpages.

HTML provides different elements such as headings, paragraphs, links, images and lists.

HTML provides the basic structure of a webpage, while CSS is used to make that webpage look attractive.

Some commonly used HTML tags are listed below:

  • Heading
  • Paragraph
  • Bold
  • Italic

  • Division
  • Span

The div element is mainly used as a block-level container, while the span element is used as an inline container.

HTML, HTML5, CSS and JavaScript

HTML is a markup language used to create the structure of a webpage.

HTML5 is the modern version of HTML and provides additional semantic elements and features.

CSS is used to control the presentation, layout, colors, fonts and overall appearance of a webpage.

JavaScript is a programming language used to add behaviour and interactivity to webpages.

Difference Between div and span

A div is a block-level element. It normally starts on a new line and can contain larger sections of content.

A span is an inline element. It is generally used to style or identify a small portion of text.
